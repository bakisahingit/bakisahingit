### What I work on

- **LLM training** — supervised fine-tuning, LoRA / PEFT, teacher–student distillation, SFT dataset curation and auditing
- **Retrieval** — RAG, GraphRAG, HippoRAG, hybrid dense + keyword search, re-ranking
- **Evaluation** — benchmarks with hard negatives and minimal pairs, calibration, reproducible experiment tracking
- **Serving** — vLLM, constrained (JSON-schema) decoding, async backends with FastAPI, Celery and Redis
- **New model classes** — diffusion language models and fast "System 1" decision models next to reasoning LLMs
